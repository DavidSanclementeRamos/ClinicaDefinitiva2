# Índice de ADRs — Catálogo de Errores Pediatric

### Validaciones de rango de edad
1. **ERR_PEDIATRIC_INVALID_AGE_RANGE**
    - Regla: RN-PEDIATRIC-001
    - Descripción: El rango de edad debe especificar edades pediátricas válidas (0-18 años).
    - [ADR-XX-ERR_PEDIATRIC_INVALID_AGE_RANGE.md](ADR-XX-ERR_PEDIATRIC_INVALID_AGE_RANGE.md)

2. **ERR_PEDIATRIC_AGE_RANGE_TOO_SHORT**
    - Regla: RN-PEDIATRIC-002
    - Descripción: El rango de edad debe tener formato válido (mínimo 5 caracteres).
    - [ADR-XX-ERR_PEDIATRIC_AGE_RANGE_TOO_SHORT.md](ADR-XX-ERR_PEDIATRIC_AGE_RANGE_TOO_SHORT.md)

---

### Advertencias clínicas y éticas
3. **WARN_PEDIATRIC_SEALANT_AGE_MISMATCH**
    - Regla: RN-PEDIATRIC-003
    - Descripción: Sellantes típicamente se aplican entre 6-14 años.
    - [ADR-XX-WARN_PEDIATRIC_SEALANT_AGE_MISMATCH.md](ADR-XX-WARN_PEDIATRIC_SEALANT_AGE_MISMATCH.md)

4. **WARN_PEDIATRIC_SEDATION_UNSPECIFIED**
    - Regla: RN-PEDIATRIC-004
    - Descripción: Técnicas de sedación deben especificar tipo (consciente/profunda).
    - [ADR-XX-WARN_PEDIATRIC_SEDATION_UNSPECIFIED.md](ADR-XX-WARN_PEDIATRIC_SEDATION_UNSPECIFIED.md)

5. **WARN_PEDIATRIC_PHYSICAL_RESTRAINT**
    - Regla: RN-PEDIATRIC-005
    - Descripción: Contención física solo debe usarse en emergencias — restricciones éticas.
    - [ADR-XX-WARN_PEDIATRIC_PHYSICAL_RESTRAINT.md](ADR-XX-WARN_PEDIATRIC_PHYSICAL_RESTRAINT.md)

---

### Materiales y manejo de lactantes
6. **ERR_PEDIATRIC_MATERIALS_TOO_SHORT**
    - Regla: RN-PEDIATRIC-006
    - Descripción: Materiales pediátricos deben describirse adecuadamente (mínimo 5 caracteres).
    - [ADR-XX-ERR_PEDIATRIC_MATERIALS_TOO_SHORT.md](ADR-XX-ERR_PEDIATRIC_MATERIALS_TOO_SHORT.md)

7. **WARN_PEDIATRIC_INFANT_MANAGEMENT_MISSING**
    - Regla: RN-PEDIATRIC-007
    - Descripción: Bebés (0-3 años) requieren técnicas de manejo específicas.
    - [ADR-XX-WARN_PEDIATRIC_INFANT_MANAGEMENT_MISSING.md](ADR-XX-WARN_PEDIATRIC_INFANT_MANAGEMENT_MISSING.md)
